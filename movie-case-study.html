🎬 Movie Streaming App – Mobile UI/UX

Designing a cinematic, intuitive movie browsing experience focused on discovery and engagement.

🚨 Problem

Users struggle to discover relevant content quickly in streaming apps due to cluttered layouts and poor categorization.

Users need a fast, visually engaging way to browse and select movies without confusion.

🎯 Goal

  • Improve movie discovery experience
  • Create visually engaging UI
  • Reduce user effort in browsing and selecting content

👤 My Role

UI/UX Designer – Responsible for wireframing, UI design, and prototyping.

🛠 Tools Used

Figma (UI Design + Prototype)

🔄 Design Process

Research → Wireframes → UI Design → Prototype → Iteration

🧠 Key Design Decisions

  • Used large movie thumbnails to enhance visual appeal
  • Created category sections for better navigation
  • Used dark theme for cinematic feel
  • Focused on clear hierarchy to highlight featured content

📱 Final UI Screens

🚀 Outcome

Created a visually rich and easy-to-navigate movie browsing experience that enhances user engagement and simplifies content discovery.

💡 What I Learned

This project helped me understand the importance of user flows, visual hierarchy, and designing for simplicity.

🔮 Future Improvements

  • Add personalized recommendations
  • Integrate search and filters
  • Improve micro-interactions
